COASTAL EXPLORER — SUNSHINE COAST

1. Extract the entire ZIP into a folder.
2. Try opening index.html in Chrome or Edge.
   If your browser blocks local pages, use Start Windows.bat or
   Start Mac.command. Those launchers need Python 3 (python.org).
   Linux: run python3 serve.py inside the extracted folder.
3. Keep your internet connection on. Wait for the real map to load,
   then choose a vehicle. No Google key is required.

WASD / arrows: drive. S: brake / reverse. Space: handbrake.
Helicopter: W/S ascend/descend, A/D yaw, arrows tilt and move.
M: map and travel between 12 towns. G: garage. R: recover.
Escape: pause. H: settings. Enable sound using the speaker button.

The region covers Caloundra to Noosa and the Sunshine Coast hinterland.
Roads and footprints use OpenStreetMap; hills use measured elevation.
Buildings, road paint and vehicles are simplified. Missing building
heights, facade details and road markings are estimates.

If you see "map providers could not be reached", use Retry in the game.
Public map services can be unavailable or blocked on some networks.
This game does not substitute a fake map when real downloads fail.

The HTML includes the engine and fonts. Maps still need internet access.
Settings > DOWNLOAD GAME FILE saves another copy from a running game.
