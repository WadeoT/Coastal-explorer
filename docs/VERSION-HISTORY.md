# Version history

Releases now use the dotted format requested for this game. The bundle previously planned as V29 is **v1.2.9**. The following bundles are **v1.3.0**, **v1.3.1**, and so on. This is a project release-number convention, not a claim of semantic-version compatibility guarantees.

| Version | State | Main changes |
| --- | --- | --- |
| [v1.3.1](v1.3.1-RELEASE.md) | Current | Source-backed architecture pilot, nearby window frames/sills and neutral glass |
| [v1.3.0](v1.3.0-RELEASE.md) | Published | Cached minimap geography, spatial map queries and measured CPU savings |
| [v1.2.9](v1.2.9-RELEASE.md) | Published | Player collisions, component combat damage, passenger seats, easier dents/crumpling, shared deformation and repair |
| [V28](V28-RELEASE.md) | Published legacy label | Graphics/performance settings, smoother suspension, roundabout fixes, crumple zones, garage spawn and fighter navigation |
| [V27](V27-RELEASE.md) | Published legacy label | Signed owner grants, solo play, visible friends' police, streaming and texture optimisation |
| [V26](V26-RELEASE.md) | Published legacy label | 200 additional car profiles, unified e-bike tab and trick controls |
| [V25](V25-RELEASE.md) | Published legacy label | Manual motorcycles, surviving wrecks, avatars, suggestions and hourly world restoration |

Older releases retain their original V-number titles, release documents and downloadable filenames. Do not rewrite or invalidate shared historical links. The current version comes from `data/version.json`; the build uses it for the garage, diagnostic report and suggestion reports, and the packager uses it for the archive filename.

Planned work and uncompleted requests are tracked in [TASKS.md](../TASKS.md); planned bundles are not presented as published releases.
