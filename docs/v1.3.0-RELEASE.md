# v1.3.0 — Smoother Navigation

Static minimap terrain, water, imagery and roads now use one reusable overscan canvas. Small movements shift its viewport rather than redraw the underlying map. Player/police contacts, airspace warnings, workshops, jobs and personal navigation still draw live. The cache rebuilds after travelling beyond its overscan, resizing, new imagery, geography changes or ten seconds. Local natural-map queries use a spatial index; large regional views retain complete coverage.

The same Chromium/SwiftShader benchmark measured minimap drawing at 3.53 ms before and 0.065 ms after caching. Overall tick medians were 5.0/5.5 ms and p95 values 10.8/7.8 ms; renderer medians varied 19.8/11.4 ms. These are controlled test samples, not a universal FPS guarantee. Both runs used 3,276 scene meshes, 255 materials and 27 textures, with zero browser exceptions.

Four deterministic checks cover reuse, moving viewport, invalidation, local/full-region coverage and bounded canvas allocation. `npm run profile` runs the browser benchmark; `npm run test:1.3.0` runs cache checks. The existing easier crumple zones and leak-before-fire crash behaviour remain.

This is the performance foundation bundle. Tank, motorcycles, 200 additional car profiles, regional airfields and light aircraft remain in v1.3.1; the uploaded building pilot follows in v1.3.2. The catalogue remains 228 vehicles in this release. See TASKS.md for uncompleted requests. Open-map endpoints rejected/timed out during runway research; the existing Sunshine Coast runway is retained rather than inventing missing airfield geometry.
