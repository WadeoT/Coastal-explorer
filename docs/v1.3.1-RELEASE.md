# v1.3.1 — Coastal Architecture

The supplied 100-building architectural pilot is now integrated into the bundled real-map loading pipeline and included with provenance/source files. IDs are normalised against existing OSM ways before adding anything. All 100 match existing structures; no duplicate buildings are created. Its 13 observed storey counts already agree with existing map tags, so no surveyed height/layout change is claimed. Unknown colours, materials and roof shapes remain unknown. Raw LiDAR elevations and estimated 3m-per-storey heights are excluded from height overrides.

Nearby windows now have shallow three-dimensional frames and sills, batched into one shared trim material. Balanced/High details are limited to 100 panes within 240m; Low uses 24 within 120m. Glass uses a more neutral blue-grey tone. These are procedural visual finishes, not measured façade reproductions. No per-window textures or scene objects are allocated.

Real-map Chromium verification matched 100 records, added zero duplicates and produced one additional facade mesh/material, with no additional textures (27 total) and no page exceptions. The sampled scene changed from 3,276 to 3,277 meshes. Timings vary by hardware; this is not a promise of higher FPS. The v1.3.0 minimap cache, easier dents/crumple zones and staged fuel-leak/fire behaviour remain.

Run `npm run test:1.3.1`, `npm run build` and `npm run profile`. Sources, unknowns and height limitations are documented in data/architecture/README.md. The existing complete coast-wide map remains; this pilot covers only its 100 identified buildings. Fleet/combat/airfield additions remain tracked in TASKS.md for v1.3.2.
