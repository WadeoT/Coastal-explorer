# v1.3.2 — Coastal Light

A procedural day/night/weather sky gradient replaces the flat background. ACES tone mapping, modest contrast/exposure adjustment, stronger paint highlights and shared normal textures add depth to roads, building finishes, water and metal. This improves lighting/surface presentation; it does not replace procedural models with photographed assets or change surveyed map geometry.

Only three 128px normal textures and one small sky texture are shared across the scene. Low and Battery Saver disable normal-map relief. No bloom, SSAO or screen-space reflection pipeline is added. The sky uses one background-layer draw. Existing resolution, render-distance, traffic and adaptive controls remain available.

Screenshot/browser checks use the real map, the game's third-person camera and the same recovery location. The sampled scene retains 3,277 meshes and 256 materials; textures increase from 27 to 31. Browser runs report zero page exceptions. Timings vary, and increased visual quality has a GPU cost; neither an exact 50% improvement nor a higher FPS is claimed.

Source-backed architecture, minimap caching, easier crumple zones and leak-first fires remain. Fleet/combat/airfield additions are still tracked in TASKS.md.

Final checks verified one sky layer, three shared normal maps, zero relief maps active on Battery Saver, restoration on Balanced and zero browser exceptions. Matched before/after screenshots were visually inspected.
