# v1.3.3 — Impact & Identity

Crashes now combine the node/beam cage with persistent local crease offsets. Front, rear, side and angled contacts leave folded surfaces instead of only moving broad shell panels. Crease influence is calculated when an impact occurs, cached per vertex and bounded to six recent impacts. The system supports cars, bikes, boats, helicopters and fighters; character meshes, instruments, glass and wheels are excluded from skin folding. Tagged wings, skids and tail surfaces can detach during severe impacts.

The four-active-cage update budget now rotates between nearby vehicles, so a multi-vehicle crash cannot permanently starve one wreck of visible deformation. Existing finite crush travel, stronger passenger-cell beams, damage/repair handling and leak-before-fire outcomes remain. This is an arcade soft-body-style approximation, not a manufacturer-calibrated full soft-body simulation.

Car hijacking previously rebuilt the selected model using career paint and tuning. It now copies the source's actual visible exterior and custom geometry, with independent materials/geometry, and bypasses the career setup for the borrowed vehicle. Existing damage and missing parts remain visible on entry. Normal owned-car selection still applies saved garage settings. Bounded paint/tuning snapshots make vehicle appearance visible to other clients; public relays remain peer-simulated.

Checks: `npm run build`, `npm run test:1.3.3`, `npm run test:public-relay`, plus beam/fire regressions. The browser test checks conflicting career paint, custom exterior geometry, actual enter/hijack flow and folds on all five classes. Fleet additions remain tracked separately in TASKS.md.

The focused browser checks passed copied exterior identity, the real hijack path, all five deformation classes and seven-car scheduling with no browser exceptions. Packet-budget checks preserve combat while trimming optional appearance/scenery data to 4 KB.

All 32 public-lobby checks passed, including cross-client paint/cosmetic upgrades, signed owner grants and fallback transports. The focused appearance packet checks also reject malformed colours without coercion errors.
