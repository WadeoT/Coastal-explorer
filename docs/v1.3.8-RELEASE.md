# v1.3.8 — Life Model Collection

The default Life Model garage tab groups all nine supplied models: 1975 Land Cruiser J50, 2010 Hyundai i20, Nissan Patrol Y60, replacement 2022-labelled Hilux, Porsche 911 GT3 RS Carrera Tribute, BMW M3 Competition Touring G81, 2020 Jeep Gladiator, ADAC rescue helicopter and Boeing F/A-18E/F Super Hornet. Existing owned IDs for the LandCruiser/i20/Hilux/Patrol/fighter are preserved; the other four are new shop entries. They are labelled by the actual supplied generation instead of retaining incompatible 79 Series/i20 N/Y62/G80 labels.

Imported cars use their modelled interior in first person. Existing aircraft dashboard controls remain functional. Wheel pivots drive suspension/steering, the rescue main rotor animates, and a separated fighter gear group retracts. The untextured rescue GLB keeps its supplied plain surface rather than claiming an observed livery. Existing wider-catalogue procedural vehicles remain available.

About 3.59 million supplied triangles become about 398,000 across all nine high-detail assets and 175,000 across lower-detail instances. Assets decode lazily into typed arrays; textures are shared, materials batched where compatible, and individual deformable chunks stay below 9,000 vertices. Low graphics, traffic/remote/interceptor roots use lower-detail meshes. There is no universal FPS claim. The standalone HTML grows from about 34 MB to about 57 MB; it still works without external model requests.

Crash checks found a legacy panel subdivider rewriting positions without matching imported colour buffers. Imported meshes now bypass that redundant refinement. Deformation/repair recomputes normals with the correct imported winding. All nine models passed selection, finite simulation, car interior visibility, wheel checks, visible mesh deformation/repair and lower-detail construction; the helicopter rotor and fighter gear passed control checks. The Life Model tab and licence/creator dialog were tested in Chrome.

The current catalogue contains 232 profiles, not 232 distinct uploaded meshes. Vehicle physics specifications remain game estimates. Sources and per-model terms are documented in LIFE-MODELS.md and the in-game MODEL CREDITS dialog. The QTopo reference is being handled in the next tracked bundle, separately from this model release.

Final wheel validation separates spare tyres and chassis trim from moving road wheels, even where source materials are shared. Geometry-derived pivots are retained in the asset data. All nine Chrome cases and both aircraft control checks passed after this correction.
